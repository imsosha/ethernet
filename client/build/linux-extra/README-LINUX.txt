=== ИНСТРУКЦИЯ ПО ЗАПУСКУ ETHERNET НА LINUX ===

Проблема "нет подходящего приложения":
В Linux файлы, скачанные или распакованные из архивов, часто не имеют флага исполнения (права на запуск).
Из-за этого система воспринимает файл как данные, а не как исполняемую программу.

СПОСОБ 1 (Самый простой — через скрипт start.sh):
1. Откройте папку с клиентом в терминале (правый клик в папке -> «Открыть в терминале»).
2. Выполните:
   chmod +x start.sh Ethernet
   ./start.sh

СПОСОБ 2 (Через графический интерфейс):
1. Кликните правой кнопкой мыши на файл "start.sh" (или "Ethernet").
2. Выберите "Свойства" (Properties) -> вкладка "Права" (Permissions).
3. Поставьте галочку "Разрешить выполнение файла как программы" ("Allow executing file as program").
4. Дважды кликните на "start.sh" и выберите "Запустить".

СПОСОБ 3 (Если используете Ethernet.desktop):
1. Кликните правой кнопкой на "Ethernet.desktop" -> "Разрешить запуск" ("Allow Launching").
2. Дважды кликните для старта.

Примечание: Скрипт start.sh автоматически выдает права на исполнение и при необходимости
добавляет флаг --no-sandbox для систем с ограниченными user namespaces (например, Ubuntu 24.04+).
