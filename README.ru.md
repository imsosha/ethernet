## ✨ Ключевые возможности

### 🎨 Кастомизация и оформление
- **Интерактивный редактор тем**: настройка акцентных цветов, палитр HSL, радиусов скруглений и прозрачности на лету с мгновенным предпросмотром.
- **Живые обои**: поддержка видео-обоев (`.mp4`, `.webm`) и картинок (`.gif`, `.png`, `.jpg`, `.webp`) с плавным бесшовным циклом.
- **Акриловое размытие (Blur)**: настраиваемый эффект матового стекла для шапки, сайдбара, меню и сообщений.
- **Ширина чата**: переключение между стандартным, широким и полноэкранным режимами.
- **Выравнивание сообщений**: настройка положения своих и чужих сообщений (слева / по центру / справа) с адаптацией хвостиков облачков.
- **Анимации**: пресеты кинетики интерфейса (*Telegram*, *Snappy*, *Smooth*, *Bouncy*, *iOS*) с настройкой длительности и кривых Безье.

### 👻 Режим невидимки (Ghost Mode)
- **Чтение без отметки**: чтение сообщений и историй без отправки статуса «просмотрено».
- **Скрытие статуса**: запрет на отправку статусов «в сети» и «печатает...».
- **Чтение по взаимодействию**: помечать сообщение прочитанным только при ответе или реакции.
- **Анти-удаление и история правок**: сохранение удалённых собеседником сообщений и локальная история изменений текста.
- **Отправка без звука**: автоматическая тихая доставка сообщений в группы или личные диалоги.

### ⚡ Оптимизация для слабых ПК
- **Отключение рендеринга NFT-подарков**: полное отключение ресурсоёмких 3D/Lottie-стикеров закреплённых подарков над профилем, в каталоге подарков и в ленте чатов, что значительно снижает нагрузку на процессор и видеокарту.
- **Умное кэширование**: минимизация потребления оперативной памяти и быстрая загрузка медиа.

### 🛡️ Встроенный прокси-движок
- Поддержка протоколов **SOCKS5** и **HTTP/HTTPS**.
- Мгновенный импорт прокси по ссылкам формата `tg://socks?server=...` и `tg://proxy?server=...`.
- Пинг-тестирование задержки и автоматическое переключение на рабочий сервер.

### 🔌 Система плагинов
- JavaScript Runtime API для создания пользовательских модификаций.
- Безопасный режим (Safe Mode) и изоляция сбоев скриптов.
- Подробное руководство: [docs/THEMES_AND_PLUGINS.md](docs/THEMES_AND_PLUGINS.md).

## 🚀 Установка и запуск

### Готовые сборки (Releases)
Готовые портативные версии для **Windows** и **Linux** доступны на странице [Releases](https://github.com/imsosha/ethernet/releases):
- **Windows**: `Ethernet-Windows-x64.exe` — портативный `.exe` (не требует установки, готов к запуску).
- **Linux**: `Ethernet-Linux-x64-Portable.tar.gz` — распакуйте архив и запустите файл `Ethernet` двойным кликом мыши (или через `./start.sh`).

---

### Сборка из исходников

#### Требования
- **Node.js**: `>= 24.11` или `>= 26.x`
- **npm**: `>= 11.x`

#### 1. Клонирование репозитория
```bash
git clone https://github.com/imsosha/ethernet.git
cd ethernet/client
```

#### 2. Установка зависимостей
```bash
npm install
```

#### 3. Запуск в режиме разработки
```bash
# Запуск Vite dev-сервера
npm run dev

# Запуск Electron
npm run app
```

#### 4. Компиляция релизных версий
```bash
# Сборка веб-бандла
npm run app:build

# Сборка Windows Portable (.exe)
npm run dist:win64

# Сборка Linux Portable (распакованная папка и tar.gz)
npm run dist:linux
```

## 📁 Структура проекта

```
ethernet/
├── client/                     # Исходный код веб-клиента и Electron-слоя
│   ├── electron/               # Главный процесс Electron, прокси, лоадер
│   │   ├── main.cjs            # Инициализация окна, трея и меню
│   │   ├── proxy-engine.cjs    # Встроенный прокси-клиент SOCKS5/HTTPS
│   │   └── notification-manager.cjs # Менеджер уведомлений
│   ├── src/                    # UI-компоненты (Teact / React-парадигма)
│   └── package.json            # Скрипты сборки и зависимости
├── themes/                     # Каталог пользовательских тем оформления (.css)
├── plugins/                    # Каталог установленных плагинов
├── wallpapers/                 # Каталог живых видео- и фото-обоев
├── docs/                       # Техническая документация
│   ├── ARCHITECTURE.md         # Архитектура и взаимодействие компонентов
│   └── THEMES_AND_PLUGINS.md   # Руководство по созданию тем и плагинов
├── ethernet-settings.json      # Конфигурация настроек по умолчанию
└── README.md                   # Документация на английском языке
```
